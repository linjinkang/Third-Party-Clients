## Contributing

欢迎提交 Pull Request 补充更多优秀的第三方客户端！请遵循以下规范：

1. **Fork** 本仓库
2. 在对应分类下按**项目名称首字母**（英文优先，中文拼音次之）排序插入条目
3. 格式：
   `| [项目名称](仓库链接) | <a href="仓库链接/stargazers"><img src="https://img.shields.io/github/stars/owner/repo?style=flat-square&label=&color=22c55e" alt="GitHub stars"></a> | <a href="仓库链接/releases"><img src="https://img.shields.io/github/release-date/owner/repo?style=flat-square&label=&color=3b82f6" alt="Release Date"></a> | ✅/❌ | ... |`
4. 平台支持情况使用 ✅（支持）/ ❌（不支持）标记；TV / Pad / iPadOS 等请注明
5. 提交 **Pull Request** 并简要说明新增项目

**提交要求：**
- 项目必须是开源的且可公开访问
- 必须是「第三方客户端」类型项目
- 项目需处于活跃维护状态（近一年内有提交）
